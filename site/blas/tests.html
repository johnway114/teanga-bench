Word forms

#

The task. Give one word form, such as a verb in a given tense, a plural, a number or a preposition fused with a pronoun.

Marking. By rule: the form must match one of the accepted forms from the course tables.

360 items · 6 languages · each asked 1 times · 1 model with a complete result

Example item from the public sample blas-morph:cornish:noun_plural:kw-decl-breselores

Prompt

Language: Cornish
Task: Give the plural (nominative plural) of the noun below.
Noun: breselores
Meaning: militant
Gender: feminine
Reply with only this one line and nothing else:
ANSWER: <answer>

Accepted answer

breseloresow

Translation

#

The task. Translate one sentence into English or out of English, or a sentence of legal or administrative text (paired with French for Breton).

Marking. By rule: chrF++, the overlap of characters and words with a reference translation, from 0 to 100%, so close translations get partial credit.

360 items · 6 languages · each asked 1 times · 1 model with a complete result

Example item from the public sample blas-translation-cornish-kw-sent-tat-1356-from_english

Prompt

Translate this English sentence into Cornish.
Reply with the Cornish translation only, on one line, with no notes or explanation.

English: Do you like dogs?

Reference translation

Yw da genes keun?

Tutor accuracy

#

The task. Check a learner's sentence: say whether it has an error, give the wrong words and the correction, and explain.

Marking. By rule: an item counts only when the error is found and fixed and nothing else changes, or a correct sentence is left alone. Two judge models mark the explanation separately.

180 items · 3 languages · each asked 1 times · 1 model with a complete result

Example item from the public sample blas-tutor-welsh-exd-bc34d0d6aa

Prompt

Check this Welsh learner sentence for at most one error.
Sentence: Mae'r dŵr yn glân.
If wrong: fix only that error (exact error_span, correction, corrected_sentence). If correct: set has_error false, leave error_span and correction empty, repeat sentence as corrected_sentence.
Reply with one JSON object only:
{"has_error": true|false, "error_span": "...", "correction": "...", "corrected_sentence": "...", "explanation": "..."}

Expected correction

glân → lân
Corrected sentence: Mae'r dŵr yn lân.

How this test set is built

What the tests measure

Teanga Bench measures how well large language models handle six Celtic languages: Irish, Welsh, Scottish Gaelic, Manx, Breton and Cornish. Every model answers the same few hundred items per test, taken from the Blas course, dictionaries and parallel corpora: lesson exercises, word forms, translation, round-trip translation, and finding and fixing errors as a tutor would. Each item is asked several times. The score is the share of items answered correctly; translation tests give partial credit for closeness to reference translations.

  • Word forms. Give one inflected form, such as a verb tense, a plural or a prepositional pronoun, marked against a list of accepted forms. 360 items.
  • Translation. Translate a sentence into or out of the language, scored by chrF++ similarity to one or more reference translations. 360 items.
  • Tutor accuracy. Find and fix the error in a sentence, or leave a correct sentence alone; an item counts only when the error is found and fixed and nothing else is changed. 180 items.

Teanga Bench is open source under Apache-2.0. Code, the public samples and every results file are on GitHub.

Gold answers come from the sources named in the methodology; they have not been reviewed by native speakers.
