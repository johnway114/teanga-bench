    Claude Code MCP configuration

    Save this as a project’s .mcp.json to connect over Streamable HTTP.

    {
  "mcpServers": {
    "blas": {
      "type": "http",
      "url": "https://blasapp.com/api/mcp"
    }
  }
}

    Community transcription requires a key with voice:transcribe. Keep credentials in your client. Neither the example nor the lookup sends a key.
