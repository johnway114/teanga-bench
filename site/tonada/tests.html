What the tests measure

Teanga Bench measures how well large language models tutor English for people whose first language is Portuguese, Spanish, Vietnamese or Japanese. Every model answers the same few hundred items per test, taken from the Tonada course and a public corpus of sentence edits: closed exercises with the instruction in the learner's language, and finding and fixing errors in English sentences as a tutor would. Each item is asked several times. The score is the share of items answered correctly.

  • Lesson exercises. Closed English exercises from the Tonada course, with the instruction in the learner's first language, marked against the accepted answers. 400 items.
  • Tutor accuracy. Find and fix the error in an English sentence, or leave a correct sentence alone; an item counts only when the error is found and fixed and nothing else is changed. 360 items.

How this test set is built

Teanga Bench is open source under Apache-2.0. Code, the public samples and every results file are on GitHub.

Gold answers come from the sources named in the methodology; they have not been reviewed by native speakers.
