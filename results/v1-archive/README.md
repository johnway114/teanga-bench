# v1 archive

The nine complete v1 runs (7 tests, 3 epochs, provider-default reasoning, 2,260 items). Each `runs/*.json` is the published file with one added field, `methodology: "v1"`. Scores were not recomputed. The Markdown report beside each JSON moved with it.

`leaderboard.json`, `leaderboard.md` and `charts/` are this board only. They are not comparable with the v2 board in `results/leaderboard.json`.

`teanga-bench publish` rebuilds the v2 board from `results/runs/` and does not rewrite these run files. The Zenodo deposit [10.5281/zenodo.24305705](https://doi.org/10.5281/zenodo.24305705) records this result set.
